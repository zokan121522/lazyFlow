## Convenciones

- **Commits**: Conventional commits con scope opcional. Prefijos: `feat:`, `fix:`, `refactor:`, `chore:`, `docs:`
- **Branch naming**: `feat/{name}` para features, `fix/{name}` para bugs
- **Board**: El proyecto usa `flow` como kanban board propio. Ver `CLAUDE.md` para comandos.
- **SDD**: Todo cambio significativo sigue el workflow Spec → Design → Tasks → Apply → Verify → Archive
